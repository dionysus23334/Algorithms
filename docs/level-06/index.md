# 第 6 级 · 常用专题算法

> **目标**：系统掌握图、字符串、区间和数论中的常见算法。

> 本章节表是目录与写作顺序；每章最终提供 Python / C++ 双版本实现、运行示例与边界用例。

## 写作约定

- 先给问题与接口，再给实现；
- Python 版优先表达算法结构；
- C++ 版展示指针、内存布局、所有权与资源管理；
