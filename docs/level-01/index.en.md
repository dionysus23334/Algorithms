# Level 1 · Programming and Algorithms: Getting Started

> **Goal**: read programs and write simple problems as code.
>
> **Status**: all eight Level 1 chapters are expanded, each with Python/C++ implementations, running examples, complexity, boundary cases, and exercises.

## Chapters

| Chapter | Content outline | Python / C++ implementation |
|---|---|---|
| 01 | [Algorithm and Program](01-algorithm-program.md) | input, processing, output; problem decomposition and execution steps | summation, extrema, counting |
| 02 | [Variables and Types](02-variables-types.md) | integers, floating-point numbers, booleans, characters and strings; type conversion | basic operations and type examples |
| 03 | [Conditions and Loops](03-conditions-loops.md) | branching, loops, termination conditions, nested loops | classification decisions, accumulation and enumeration |

## Writing conventions

- Give the problem and the interface first, then the implementation;
- The Python version expresses the algorithm structure first;
- The C++ version demonstrates pointers, memory layout, ownership and resource management;
- Each chapter contains at least: normal cases, boundary cases, complexity analysis, exercises.
