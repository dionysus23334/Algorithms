# 第 2 级 · 算法分析基础

> **目标**：理解正确性与效率，能够比较不同解法。
>
> **状态**：第 2 级 7 章已展开；每章含 Python / C++ 实现、复杂度、边界用例与练习。

## 章节

| 章 | 内容大纲 | Python / C++ 实现 |

| 01 | [问题定义](01-problem-definition.md) | 输入输出、约束、前置条件、合法结果 | 函数约定与输入检查 |

## 写作约定

- 先给问题与接口，再给实现；
- Python 版优先表达算法结构；
- C++ 版展示指针、内存布局、所有权与资源管理；
- 每章至少包含：正常用例、边界用例、复杂度分析、练习。
