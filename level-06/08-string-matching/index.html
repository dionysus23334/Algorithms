    6.8 字符串匹配¶

    级别：第 6 级 · 常用专题算法
    状态：已展开。

    学习目标¶

    • 写朴素匹配；
    • 理解前缀函数与 KMP；
    • 用 Z 算法找重复结构。

    朴素匹配¶

    1def naive_find(text: str, pat: str) -> int:
2    n, m = len(text), len(pat)
3    for i in range(n - m + 1):
4        if text[i:i+m] == pat:
5            return i
6    return -1

    最坏 \(O(nm)\)。

    KMP 前缀函数¶

    pi[i]：pat[:i+1] 的最长相等真前缀/后缀长度。

     1def prefix_function(p: str) -> list[int]:
 2    pi = [0] * len(p)
 3    j = 0
 4    for i in range(1, len(p)):
 5        while j > 0 and p[i] != p[j]:
 6            j = pi[j - 1]
 7        if p[i] == p[j]:
 8            j += 1
 9        pi[i] = j
10    return pi
11
12def kmp_find(text: str, pat: str) -> int:
13    if not pat:
14        return 0
15    pi = prefix_function(pat)
16    j = 0
17    for i, ch in enumerate(text):
18        while j > 0 and ch != pat[j]:
19            j = pi[j - 1]
20        if ch == pat[j]:
21            j += 1
22        if j == len(pat):
23            return i - len(pat) + 1
24    return -1

    时间 \(O(n+m)\)。

    Z 算法¶

    z[i]：s 与 s[i:] 的最长公共前缀长度。可用于找所有匹配、周期。

    C++ KMP¶

     1#include <string>
 2#include <vector>
 3
 4std::vector<int> prefix_function(const std::string& p) {
 5    std::vector<int> pi(p.size(), 0);
 6    for (int i = 1, j = 0; i < static_cast<int>(p.size()); ++i) {
 7        while (j > 0 && p[i] != p[j]) j = pi[j - 1];
 8        if (p[i] == p[j]) ++j;
 9        pi[i] = j;
10    }
11    return pi;
12}

    边界¶

    场景 注意
    空模式 通常返回 0
    模式比文本长 返回 -1
    重叠匹配 KMP 可继续找下一个
    Unicode 按字节/码点，需统一

    练习¶

    1. 返回所有匹配位置。
    2. 用前缀函数求字符串的最小周期。
    3. 用 Z 算法实现匹配。
