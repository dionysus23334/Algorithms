# 第 3 级 · 基础数据结构

> **目标**：掌握数据的组织方式及其操作代价。
>
> 本章节表是目录与写作顺序；每章最终提供 Python / C++ 双版本实现、运行示例与边界用例。

## 章节

| 章 | 内容大纲 | Python / C++ 实现 |
|---|---|---|
| 01 | [存储与节点](01-storage-nodes.md) | 连续存储、节点、对象引用；指针、生命周期、所有权 | Python 引用连接；C++ 指针与资源管理 |
| 02 | [动态数组](02-dynamic-array.md) | 索引访问、插入删除、容量、扩容、摊还代价 | 教学实现；list / vector |
| 03 | [链表](03-linked-list.md) | 单链表、双链表、插入、删除、反转 | 双语言节点与链表实现 |
| 04 | [栈](04-stack.md) | 后进先出、括号匹配、表达式处理 | 手写栈；list / stack |
| 05 | [递归与调用栈](05-recursion-stack.md) | 基本情况、展开与返回、归纳证明、递归深度 | 递归与迭代转换 |
| 06 | [队列与双端队列](06-queue-deque.md) | 先进先出、循环队列、两端操作 | 手写循环队列；deque / queue |
| 07 | [哈希表与集合](07-hash-table.md) | 哈希函数、冲突、负载因子、平均与最坏代价 | 手写哈希表；dict / set；无序关联容器 |
| 08 | [树与二叉树](08-trees-binary.md) | 根、子树、深度；前中后序与层序遍历 | 节点定义、递归与迭代遍历 |
| 09 | [二叉搜索树](09-bst.md) | 查找、插入、删除、树高与退化 | 手写二叉搜索树 |

| 12 | [图的存储](12-graph-storage.md) | 有向图、无向图、边权、邻接表、邻接矩阵 | 建图与基本操作 |

## 写作约定

- 先给问题与接口，再给实现；
- Python 版优先表达算法结构；
- C++ 版展示指针、内存布局、所有权与资源管理；
- 每章至少包含：正常用例、边界用例、复杂度分析、练习。
