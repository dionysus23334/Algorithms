# Glossary

> Common abbreviations and terms used in the algorithm notes. On first occurrence the prose expands them into the full English name and the Chinese meaning; this page collects them in one place for easy lookup.

| Abbreviation | Full name | Meaning |
|---|---|---|
| **ADT** | Abstract Data Type | Abstract data type: exposes operations only, not the implementation |
| **BFS** | Breadth-First Search | Breadth-first search |
| **DFS** | Depth-First Search | Depth-first search |
| **DAG** | Directed Acyclic Graph | Directed acyclic graph |
| **DP** | Dynamic Programming | Dynamic programming |
| **DSU** | Disjoint Set Union | Disjoint set union |
| **MST** | Minimum Spanning Tree | Minimum spanning tree |
| **SSSP** | Single-Source Shortest Path | Single-source shortest path |
| **APSP** | All-Pairs Shortest Path | All-pairs shortest path |
| **LIS** | Longest Increasing Subsequence | Longest increasing subsequence |
| **LCS** | Longest Common Subsequence | Longest common subsequence |
| **LCA** | Lowest Common Ancestor | Lowest common ancestor |
| **BST** | Binary Search Tree | Binary search tree |
| **AVL** | Adelson-Velsky and Landis tree | AVL balanced binary search tree |
| **SCC** | Strongly Connected Component | Strongly connected component |
| **HLD** | Heavy-Light Decomposition | Heavy-light decomposition |
| **KMP** | Knuth–Morris–Pratt | KMP string matching algorithm |
| **FFT** | Fast Fourier Transform | Fast Fourier transform |
| **GCD** | Greatest Common Divisor | Greatest common divisor |
| **LCM** | Least Common Multiple | Least common multiple |
| **NP** | Nondeterministic Polynomial time | Nondeterministic polynomial time |
| **NPC** | NP-Complete | NP-complete |
| **NP-hard** | NP-hard | NP-hard |
| **RAM** | Random Access Machine | Random access machine |
| **I/O** | Input/Output | Input/output |
