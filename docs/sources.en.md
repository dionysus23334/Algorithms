## Usage principles

1. **Do not copy** textbook or wiki text wholesale; rewrite it in your own structure.
2. Code is primarily this site's own teaching implementations; reference implementations are only used to check interfaces, boundaries and complexity.
3. When citing CC BY-SA / CC BY-NC-SA content, keep the source link and the license statement.
4. Do not directly copy code whose license is unclear (especially some KACTL files).
5. At the end of each chapter, list the sources actually used for that chapter rather than only a master table on this page.
