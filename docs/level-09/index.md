# 第 9 级 · 算法理论与计算边界

> **目标**：理解问题是否可解、资源限制，以及近似和随机化的意义。
>
> **状态**：第 9 级 10 章已展开；每章含 Python / C++ 实现、复杂度、边界用例与练习。

| 章 | 内容大纲 | Python / C++ 实现 |

## 写作约定

- 先给问题与接口，再给实现；
- Python 版优先表达算法结构；
- C++ 版展示指针、内存布局、所有权与资源管理；
- 每章至少包含：正常用例、边界用例、复杂度分析、练习。
