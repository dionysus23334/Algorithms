# 第 5 级 · 核心算法设计方法

> **目标**：能够推导解法，解释算法为什么成立。
>
> 本章节表是目录与写作顺序；每章最终提供 Python / C++ 双版本实现、运行示例与边界用例。

## 章节

| 章 | 内容大纲 | Python / C++ 实现 |
|---|---|---|
| 01 | [分治](01-divide-conquer.md) | 划分、递归求解、合并 | 归并排序、快速排序、快速选择 |
| 02 | [递归复杂度](02-recursion-complexity.md) | 递推式、递归树、代入法、主定理入门 | 调用次数与层次统计 |

| 04 | [回溯](04-backtracking.md) | 状态、选择、撤销、结果收集 | 子集、排列、组合、N 皇后 |

| 06 | [贪心](06-greedy.md) | 局部选择、交换论证、失败反例 | 区间调度、Huffman 编码 |

## 写作约定

- 先给问题与接口，再给实现；
- Python 版优先表达算法结构；
- C++ 版展示指针、内存布局、所有权与资源管理；
- 每章至少包含：正常用例、边界用例、复杂度分析、练习。
